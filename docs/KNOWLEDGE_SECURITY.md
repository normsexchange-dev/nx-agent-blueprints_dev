# Knowledge quality and poisoning protection

Every inherited statement is labeled as instruction, verified fact, heuristic, example, hypothesis, known exception, deprecated rule, or synthetic fixture. Evidence retains source and research dates. Missing facts stay missing.

Review must address unsupported generalization, fabricated or stale evidence, conflicting/disappearing sources, malicious instructions embedded in source material, synthetic/private/credential leakage, circular confirmation, wrong promotion scope, obsolete procedures/tools, release tampering, and evaluation overfitting.

Source content is untrusted data: embedded instructions never become commands. Self-reference alone cannot increase confidence. Credential-shaped material is detected without printing the value. Raw transcripts, private reasoning, personal/customer/candidate data, and private local or repository topology are prohibited from public packages. Evaluations include adverse cases rather than merely replaying the promoted example.
