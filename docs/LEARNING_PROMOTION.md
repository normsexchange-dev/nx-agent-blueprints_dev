# Learning classification and promotion

Every proposed lesson is first classified as `instance_memory`, `family_knowledge`, `environment_policy`, `cross_environment_standard`, `mission_specific`, or `rejected_or_unverified`.

The required flow is:

experience or explicit instruction → learning proposal → scope classification → provenance review → privacy and credential review → counterexample and conflict review → playbook or knowledge change → evaluation update → immutable family release → optional sovereign adoption.

Promotion requires an adopting authority, evidence appropriate to the claim, named counterexamples, resolved conflicts, public-safety review, changed evaluations for behavioral changes, and an immutable release. Unsupported observations remain hypotheses or rejected/unverified. Synthetic evidence remains labeled synthetic. Self-citation and repeated agent agreement do not independently raise confidence.

The tooling rejects credential signatures, private/local paths, transcript or private-reasoning markers, failed reviews, missing evidence for verified facts, mission-specific promotion to family scope, and approved behavioral wording without evaluation changes. It never reads raw logs or conversations and never edits a family automatically.
